# KIT.md — Prompt Reproduction and Rights Kit

**Purpose:** turn one prompt from the collection into a documented, reproducible creative experiment, not a guarantee that different models will produce identical results.

## Read first
- `README.md`
- `LICENSE`
- prompt category and any attribution/usage notes
- target model's current terms, privacy policy and commercial-use terms

## Requirements artefacts
For each selected prompt record prompt ID/text, intended result, model and version/date, aspect ratio/settings, input/reference asset rights, safety/content constraints, output link, edits made, and reproducibility limitations. Keep prompt text, generated output and source assets separately identified.

## Low-cost procurement
Start with available free usage and non-proprietary tools. Verify current quotas and commercial rights before relying on any service. Do not buy credits or subscriptions until a small experiment demonstrates value. Never upload confidential, personal or third-party material without permission.

## Procedure
1. Choose one prompt and define a measurable visual brief.
2. Record model/version and settings before generation.
3. Verify rights for reference images, trademarks, likenesses and source material.
4. Run one baseline; record output and deviations.
5. Change one variable at a time for comparisons.
6. Document failures and model-specific behaviour.
7. Publish only outputs that meet rights, privacy and safety requirements.

## Acceptance
- [ ] Prompt and settings are recorded.
- [ ] Source assets have a documented rights basis.
- [ ] Output is labelled as generated and model/date are noted.
- [ ] Cost/quota and commercial-use limits are checked.
- [ ] A repeat attempt and comparison are documented.
- [ ] No promise of exact reproducibility is made.
